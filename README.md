# 세스코 연구원을 위한 AI 그림책 (CESCO Lab AI Playbook)

> **화학공학·이물 분석 연구원을 위한 실전 AI 그림책 및 업무 에이전트 가이드**  
> GitHub Pages 웹 링크를 통해 별도 설치 없이 PC나 모바일에서 즉시 열람할 수 있습니다.

---

## 📖 전체 목차

| 권 | 제목 | 핵심 내용 |
|---|---|---|
| **1권** | AI는 어떻게 말을 할까 | 토큰, 확률 기반 단어 생성, 다이얼(파라미터) 학습, 환각의 원리 |
| **2권** | AI와 대화 잘하기 | 컨텍스트 창(실험대), 기억의 비밀, SOP 프롬프트, FT-IR 스펙트럼 임베딩, RAG |
| **3권** | AI가 일을 하게 하기 | 도구 사용(Tool Use), 생각-행동-관찰 에이전트 루프, MCP(USB-C), 안전 장치 |
| **4권** | 내 일에 AI 쓰기 | 보안 신호등, 이물 분석 보고서 요약, 엑셀 정리, 재현성 검증 시험 |
| **5권** | AI가 보는 세상과 앞으로 | 멀티모달 현미경 사진 판독의 한계, 모델 체급 선택, 연구원의 책임 |
| **특강** | AI 에이전트 사용에 중요한 3가지 | 파인튜닝 없이 지침(Hook), 스킬(Skill), 검증(Harness)으로 가르치기 |
| **실전** | 세스코 업무에 녹이기 | 업무 소개, 입력 양식 하나로 3개 안 받고 10분 뒤 고르기, 3일 완성 |

## 🛠 아키텍처 및 소스 구조

유지보수와 검증을 위해 소스코드는 **1장 1파일 및 공통 모듈**로 분리되어 있으며, 빌드 시 **단일 독립 HTML(`index.html`)**로 자동 번들링됩니다.

```text
cesco-lab-ai-playbook/
├── index.html                  # GitHub Pages 배포용 단일 실행 파일
├── 연구원을_위한_AI_그림책.html # 로컬/오프라인 공유용 단일 파일
├── src/
│   ├── core/                   # 공통 엔진, 컴포넌트, 스타일
│   │   ├── styles.css          # 공통 UI 스타일
│   │   ├── api.js              # SVG / 3D Canvas 드로잉 헬퍼
│   │   ├── components.js       # 공통 드로잉 컴포넌트 (bot, person, pill 등)
│   │   └── runtime.js          # 책장, 네비게이션, 페이지 턴 런타임
│   └── volumes/                # 1장 1파일 본문 데이터
│       ├── vol1/ ~ vol7/
│       │   ├── meta.js         # 권 메타데이터 및 표지 장면
│       │   ├── chap1.js ~      # 각 장별 제목, 리드, 본문, 비유, 퀴즈, 장면 함수
│       │   └── recap.js        # 정리 및 다음 권 예고
├── scripts/
│   ├── harness.js              # 하네스 검증 스크립트 (누락·오류·규칙 자동 검사)
│   └── build.js                # 단일 HTML 번들러 빌드 스크립트
└── .github/workflows/
    └── deploy.yml              # GitHub Pages 자동 배포 CI/CD 파이프라인
```

## 🛡️ 검증 하네스(Harness) 실행

빌드나 커밋 전에 모든 권과 장의 무결성을 자동으로 검증합니다:

```bash
npm test
# 또는
node scripts/harness.js
```

- **검증 항목**:
  1. 각 장의 필수 필드(title, tag, lead, body, lab, quiz, scene) 누락 여부
  2. 퀴즈 문항 및 정답 인덱스 유효성
  3. 금지 규칙(긴 대시 `—`, `–` 미사용) 준수 여부
  4. 런타임 구문 및 재조립 정합성 검사

## 🚀 빌드 방법

```bash
npm run build
# 또는
node scripts/build.js
```
하네스 검증을 자동으로 통과한 뒤, 최신 `index.html`과 `연구원을_위한_AI_그림책.html`을 생성합니다.
